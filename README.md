## Subir a GitHub
1. Descomprime el ZIP.
2. Entra en tu repositorio `dkgl-web/tips`.
3. Sube **index.html**, **style.css**, **app.js** y la carpeta **assets** a la raíz del repositorio.
4. Haz Commit.
5. Si GitHub Pages aún no está activado: Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

URL prevista:
https://dkgl-web.github.io/tips/

## Importante
Para añadir contenido nuevo en el futuro no hace falta cambiar la navegación ni la estructura general: basta con añadir tarjetas dentro de la sección correspondiente.
